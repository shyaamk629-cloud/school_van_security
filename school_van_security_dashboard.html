Technical Architecture: IoT, DNN & GenAI Mini Project Specification
End-to-end telemetry pipeline integrating embedded edge sensors, deep neural anomaly inference, and conversational safety synthesis.
1
IoT Edge Telemetry & Sensory Acquisition

Hardware sensors installed inside school vans continuously stream environmental, physical, and behavioral telemetry via MQTT/HTTP protocols. Key sensor nodes include OBD-II vehicle speed & RPM bus, magnetic door interlock reed switches, DHT22 cabin temperature & humidity transducers, GPS NEO-6M modules, IR break-beam seat occupancy matrices, and driver SOS emergency panic switches.

ESP32 / Raspberry Pi Edge Gateway OBD-II CAN Bus (ISO 15765-4) MQTT Mosquitto Broker Payload: JSON Vector 10Hz
2
Telemetry Preprocessing & Feature Engineering

Raw asynchronous sensory packets are ingested by the streaming pipeline, min-max normalized, aligned via sliding temporal windows, and checked for packet dropouts. Feature vectors are constructed by fusing spatial GPS coordinates with vehicle dynamics (speed, acceleration delta, door open status while speed > 5 km/h).

Sliding Temporal Window (t=3s) Kalman Filter Smoothing Feature Normalization [0, 1]
3
DNN-Based Multi-Class Threat Classification

A Deep Neural Network (Dense MLP / Temporal CNN) processes normalized feature tensors to classify situational safety states. The model infers whether the telemetry signature represents benign driving or hazardous conditions (e.g. overspeeding in school zones, door opened while in motion, hyperthermic cabin spike, seat overcapacity, or collision panic).

Multi-Layer Perceptron (MLP) TensorRT / ONNX Runtime Edge Softmax Cross-Entropy Loss Confidence Metrics > 95%
4
GenAI Contextual Safety Copilot & Report Synthesis

When an anomaly is flagged by the DNN, the Generative AI reasoning agent ingests the structured incident payload, historical van logs, and school district safety protocols. It synthesizes root-cause explanations in plain natural language, advises operators on recommended dispatches, and auto-drafts regulatory incident reports.

Google Gemini 2.5 Flash API Few-Shot Safety Grounding Automated Incident Documentation Parent SMS Alert Templates
5
Central Monitoring Command Center & Driver Response

The reactive single-page dashboard provides school transport administrators with interactive visualization, alarm management, geofence compliance monitoring, and two-way dispatch response. Critical threats trigger automated audible chimes, in-cabin driver buzzer actuation, and dispatcher escalation workflows.
